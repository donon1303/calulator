# calculator.py

Минималистичный GUI-калькулятор на Tkinter (стандартная библиотека Python).

Приложение построено вокруг одного класса `Calculator`, унаследованного от `tk.Tk`, который одновременно является окном приложения и хранит всё состояние вычислений.

## Возможности

- Базовые арифметические операции: `+`, `-`, `×`, `÷`
- Дополнительные функции: `√` (квадратный корень), `x²` (возведение в квадрат), `±` (смена знака)
- Память калькулятора: `M+`, `M-`, `MR`, `MC`
- История вычислений с возможностью клика для повторного использования результата
- Переключение тёмной и светлой темы оформления
- Копирование результата в буфер обмена (`Ctrl+C`)
- Полное управление с клавиатуры

## Требования

Только стандартная библиотека Python — модуль `tkinter` входит в большинство дистрибутивов.

Если `tkinter` не установлен (актуально для некоторых сборок Linux):

```bash
sudo apt install python3-tk
```

## Запуск

```bash
python calculator.py
```

## Структура файла

| Часть | Назначение |
|---|---|
| `THEMES` | Словарь с двумя наборами цветов (`dark` и `light`) для всех элементов интерфейса |
| Константы шрифтов | `FONT_DISPLAY`, `FONT_SUB`, `FONT_BTN`, `FONT_HISTORY_TITLE`, `FONT_HISTORY` |
| `format_result(value)` | Форматирует число для отображения (убирает `.0`, обрезает хвостовые нули) |
| `Calculator` | Класс окна приложения — вся логика и интерфейс |

## Класс `Calculator`

Методы сгруппированы по назначению:

**Построение интерфейса**
`_build_topbar`, `_build_display`, `_build_buttons`, `_make_button`, `_build_history_panel`

**Тема оформления**
`_apply_theme`, `_toggle_theme`, `_toggle_history`

**Логика вычислений**
`_on_button`, `_input_digit`, `_clear`, `_backspace`, `_set_operation`, `_calculate`, `_unary`, `_toggle_sign`, `_apply`

**Память**
`_memory_add`, `_memory_subtract`, `_memory_recall`, `_memory_clear`, `_update_memory_label`

**История**
`_add_history`, `_clear_history`, `_recall_history`

**Вывод и буфер обмена**
`_refresh`, `_copy_to_clipboard`

**Клавиатура**
`_bind_keys`

Подробное описание каждого метода — в `calculator_documentation.docx`.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `0`–`9`, `.` | Ввод цифр и десятичной точки |
| `+` `-` `*` `/` | Арифметические операции (`*` и `/` соответствуют `×` и `÷`) |
| `Enter` / `Num Enter` | Вычислить результат (`=`) |
| `Backspace` | Удалить последний символ |
| `Esc` | Очистить (`C`) |
| `Ctrl+C` | Скопировать результат в буфер обмена |
| `t` | Переключить тему (тёмная / светлая) |
| `h` | Показать / скрыть панель истории |
