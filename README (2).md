# calculator.py

Расширенный GUI-калькулятор на Tkinter (стандартная библиотека Python).

## Возможности

### Основные
- `+`, `-`, `×`, `÷`
- `√` — квадратный корень
- `x²` — квадрат числа
- `±` — смена знака
- `⌫` — удалить последний символ
- `C` — полный сброс

### Память
- `M+` — добавить текущее число в память
- `M-` — вычесть текущее число из памяти
- `MR` — получить значение из памяти
- `MC` — очистить память

### История
- Все вычисления сохраняются в боковой панели.
- Нажатие на запись истории возвращает её результат.
- Историю можно полностью очистить.
- Панель можно скрыть клавишей `H`.

### Темы
- Тёмная и светлая тема.
- Переключение кнопкой `☾/☀` или клавишей `T`.

### Научный режим
Научная панель скрыта по умолчанию, поэтому обычный калькулятор остаётся компактным.

Нажмите `ƒx` или клавишу `S`, чтобы открыть её.

Доступны:

| Кнопка | Назначение |
|---|---|
| `sin` | синус |
| `cos` | косинус |
| `tan` | тангенс |
| `log` | десятичный логарифм |
| `ln` | натуральный логарифм |
| `π` | число Пи |
| `e` | число Эйлера |
| `1/x` | обратное число |
| `x!` | факториал |
| `%` | деление числа на 100 |

### DEG / RAD

Кнопка `DEG/RAD` переключает единицы измерения углов:

- `DEG` — градусы: `sin(90) = 1`
- `RAD` — радианы: `sin(π/2) = 1`

Переключение также доступно клавишей `R`.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `0`–`9`, `.` | ввод числа |
| `+` `-` `*` `/` | арифметические операции |
| `Enter` | вычислить |
| `Backspace` | удалить символ |
| `Esc` | очистить |
| `Ctrl+C` | скопировать результат |
| `T` | сменить тему |
| `H` | показать/скрыть историю |
| `S` | показать/скрыть научный режим |
| `R` | переключить DEG/RAD |

## Почему добавлен научный режим

Изначальная версия уже имела основные операции, память, историю, темы и управление клавиатурой. Поэтому добавление ещё одной простой арифметической функции почти не расширило бы возможности программы.

Научный режим превращает проект из обычного калькулятора в более полноценный учебный инструмент. При этом он не перегружает интерфейс: дополнительные кнопки скрыты до тех пор, пока пользователь их не включит.

Особенно полезны:
- `sin`, `cos`, `tan` — для тригонометрии;
- `log`, `ln` — для математического анализа;
- `x!` — для комбинаторики и вероятности;
- `π`, `e` — для формул;
- `DEG/RAD` — чтобы корректно работать с углами.

Все функции реализованы через стандартный модуль Python `math`, поэтому сторонние библиотеки по-прежнему не нужны.

## Запуск

```bash
python calculator.py
```

Если команда `python` не работает в Windows, попробуйте:

```bash
py calculator.py
```

## Требования

- Python 3.x
- Tkinter
- стандартная библиотека Python

Дополнительные `pip install` не требуются.
